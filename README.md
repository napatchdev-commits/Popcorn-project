# 🍿 สมุดป๊อบคอร์น (Popcorn Ledger)

เว็บแอปพลิเคชันบันทึกรายรับ-รายจ่ายสำหรับร้านขายป๊อบคอร์น ใช้งานง่ายบนมือถือ พร้อมระบบจัดเก็บข้อมูลลงบน Google Sheets แบบเรียลไทม์ผ่าน Google Apps Script

---

## ✨ ฟีเจอร์เด่น
- 💵 **บันทึกรายรับ-รายจ่ายรวดเร็ว**: สลับโหมดรับ-จ่ายได้ทันที พร้อมชิปเลือกรายการค่าใช้จ่ายประจำ (เช่น ข้าวโพด, น้ำมัน, ถุง)
- 📊 **สรุปยอดแบบเรียลไทม์**: แสดงยอดรายรับ รายจ่าย และกำไรสุทธิประจำวัน และสรุปภาพรวมแยกตามเดือน
- 🏷️ **จัดการรายการจ่าย**: เพิ่ม/ลบหมวดหมู่รายการจ่ายได้เองตามต้องการ
- 🔐 **ระบบรหัส PIN**: ป้องกันการเข้าถึงข้อมูลโดยไม่ได้รับอนุญาต
- 📱 **Mobile-First & PWA Ready**: ออกแบบมาสำหรับใช้งานบนสมาร์ตโฟนโดยเฉพาะ รองรับทั้ง Light และ Dark mode
- ⚙️ **ติดตั้งง่าย**: กำหนด Web App URL และ PIN ผ่านหน้าเว็บได้ทันที หรือระบุตายตัวในโค้ด

## 🚀 ขั้นตอนการติดตั้งและการใช้งาน

### 1. ตั้งค่าฐานข้อมูลบน Google Sheets & Google Apps Script
1. สร้าง **Google Sheet** เปล่าขึ้นมา 1 ไฟล์
2. ไปที่เมนู **ส่วนขยาย (Extensions)** > **Apps Script**
3. ลบโค้ดเดิมออกทั้งหมด แล้วคัดลอกโค้ดจากไฟล์ [`Code.gs`](Code.gs) ไปวาง
4. (ตัวเลือก) เปลี่ยนรหัส PIN ในบรรทัด `const PIN = '1234';` เป็นรหัสที่ต้องการ
5. คลิกปุ่ม **ทำให้ใช้งานได้ (Deploy)** > **การทำให้ใช้งานได้รายการใหม่ (New deployment)**
6. เลือกประเภทเป็น **เว็บแอป (Web app)** และตั้งค่า:
   - **คำอธิบาย**: Popcorn API
   - **เรียกใช้ในฐานะ (Execute as)**: `ฉัน (Me)`
   - **ผู้มีสิทธิ์เข้าถึง (Who has access)**: `ทุกคน (Anyone)` *(สำคัญมาก)*
7. กด **ทำให้ใช้งานได้ (Deploy)** และคัดลอก **URL ของเว็บแอป** (ที่ลงท้ายด้วย `/exec`)

---

### 2. นำขึ้นใช้งานบน Vercel หรือ Web Hosting
1. นำโปรเจกต์นี้ขึ้น Git / GitHub
2. นำเข้าโปรเจกต์บน [Vercel](https://vercel.com) (Deploy ได้ทันทีโดยไม่ต้อง Build)
3. เปิดหน้าเว็บไซต์:
   - ในการเข้าใช้งานครั้งแรก ระบบจะแสดงหน้าจอตั้งค่า
   - วาง URL ของ Apps Script (จากขั้นตอนที่ 1) และรหัส PIN
   - กด **"บันทึกและเชื่อมต่อ"** เพื่อเริ่มใช้งานทันที
